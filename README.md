# ThinkSteps

**転職を考え始めたときに、「何を変えたいのか」を自分で整理するWebアプリ**

理想・現状・問題・原因・課題・手段を順に考えます。
AIは答えや助言を出さず、考えの取り違えに気づくための問いだけを返します。

## 解決したいこと

転職を考え始めた際、何を変えたいのかを整理する前に、「転職する」という手段から考えてしまうと、転職が本質的な悩みの解決に繋がらない可能性があります。

ThinkStepsでは、組織の業務改善で使われる問題解決の手順(理想と現状の差を問題とし、原因から課題と手段を導く)を使って、転職の悩みを整理することを手伝います。
この手順では、問題と課題、手段と理想など、近い概念を取り違えやすいと考えられます。そこで、記入しながら取り違えに気づけるよう、AIが問いを返します。

**対象ユーザー**: 転職を考え始めたが、まだ具体的に動いていない20代から30代前半の社会人

背景の根拠と、このアプリで確かめたい仮説は [設計思想](docs/concept.md) を参照してください。

## 使い方

1. 今考えていることを、自由に書きます(任意)。
2. 7つのステップを順に入力します。
3. AIの問い返しを受けて、書き直すか、そのまま進むかを選びます。
4. 最後に、自分で考えた問題の構造を図で確認します。

| No | ステップ | 考えること |
|---|---|---|
| 1 | 理想 | 仕事や働き方を通じて、どんな状態を実現したいか |
| 2 | 前提・制約(任意) | 変えられない、または今回は変えないと決めた条件は何か |
| 3 | 現状 | 理想と同じ観点で見ると、今はどんな状態か |
| 4 | 問題 | 理想と現状の差は何か |
| 5 | 原因 | その差を生み出している要素は何か |
| 6 | 課題 | 問題を解くために、どんな方向で取り組むか |
| 7 | 手段 | 課題に取り組むために、具体的に何をするか(転職も手段の一つ) |

### 例: 品質管理の仕事にやりがいを感じない人(架空の人物)

| ステップ | 入力 | AIの問い返し |
|---|---|---|
| 理想 | 転職したい | 転職した先で、どんな状態になっていたいですか？ |
| 理想(書き直し) | 自分の工夫が成果につながったと実感できる仕事をしている | (問い返しなし) |
| 現状 | 給料が低い | 理想では仕事での手応えについて書いていますが、現状は何について書いていますか？ |
| 現状(書き直し) | 担当業務の多くは決まった検査手順の繰り返しで、自分で工夫できる場面がほとんどない | (問い返しなし) |

## 特徴

- **AIは答えや助言を出しません。** 自分で深掘りして「何を変えたいのか」を言葉にすることが、このアプリの目的だからです。正しい記入例や解決策、転職すべきかどうか、向いている職種などは示さず、気づくための問いを1つだけ返します。
- **転職は手段の一つとして扱います。** 理想や問題に「転職したい」と書いた場合は、転職で実現したいことを問い返します。手段として書いた場合は、そのまま受け入れます。
- **取り違えやすい箇所でステップを分けています。** 変えられない条件(前提・制約)、取り組む方向性(課題)、具体的な行動(手段)を分けています。
- **AIの判定は絶対ではありません。** 指摘に納得できなければ、そのまま次に進めます。
- **安心して使えるよう配慮しています。** 心身の不調など深刻な内容が入力された場合は、判定を止めて公的な相談窓口を案内します。入力内容は保存しません。

## 限界と注意事項

- AIの判定は誤ることがあります。指摘は仮説として扱ってください。
- このアプリは、転職すべきかどうかを判断するものではありません。
- 入力内容は、判定のために外部のAIサービス(OpenAI API)に送信されます。職場名や人名など、個人や組織が特定できる情報は入力しないでください。
- 入力内容は保存されません。
- 心身の不調などでつらいときは、アプリの画面下部にある公的な相談窓口を利用してください。
