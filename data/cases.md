# 架空の人物と記入例

> 本書は、転職を考え始めた架空の人物と、全ステップの適切な記入例をまとめる。
> 記入例は、次の用途で使う。
> - テストデータ(data/testcases.csv)の文脈と、判定の見本
> - 思考フレームワーク(thinking_framework.md)の例文
> - 画面の入力欄に表示する記入例
>
> 人物、職場、状況はすべて架空である。
> 記入例は「適切な書き方の一例」であり、唯一の正解ではない。

---

## 人物の一覧

| ID | 人物 | 確かめたい難しさ(設計思想の仮説3) |
|---|---|---|
| P01 | Aさん(29歳、食品メーカーの品質管理、7年目) | 理想が定まっていない |
| P02 | Bさん(32歳、小売チェーンの副店長、子ども1人) | 前提・制約が多い |
| P03 | Cさん(24歳、ホテルのフロント、3年目) | 手段が理想に入り込みやすい |

各人物の記入例では、手段の結論をあえて分けている(P01は社内での取り組み、P02は転職を含む、P03は転職の前の準備)。
アプリが転職を勧めたり止めたりするものではなく、転職を手段の一つとして扱うことを示すためである。

## P01 Aさん: 理想が定まっていない

### 状況
食品メーカーの工場で、品質管理の仕事を7年続けている。毎日の仕事はこなせているが、やりがいを感じない。
同年代の知人が転職したという話を聞き、自分も転職したほうがいいのか迷っている。
ただ、何がしたいのかは自分でも分からない。

### 最初に書きそうな悩み(自由記述)
> 転職したほうがいいのか迷っている。でも、何がしたいのか分からない。

### 適切な記入例
| ステップ | 記入例 |
|---|---|
| 理想 | 自分の工夫が成果につながったと実感できる仕事をしている |
| 前提・制約 | 年収は今より下げない／今の住まいから通える範囲で働く |
| 現状 | 担当業務の多くは決まった検査手順の繰り返しで、自分で工夫できる場面がほとんどない |
| 問題 | 仕事の中で工夫して成果を出す場面がなく、手応えを感じられていない |
| 原因 | 検査の手順が細かく決められていて、進め方を任される仕事がない |
| 課題 | 自分の工夫が成果に反映される仕事の範囲を広げる |
| 手段 | 検査手順の見直しを任せてもらえるよう、上司に相談する |

### 起きやすい取り違え
| ステップ | 入力しそうな文 | 起きていること |
|---|---|---|
| 理想 | 転職したい | 手段を理想に書いている |
| 理想 | やりがいのある仕事がしたい | 何があれば「やりがい」なのか特定できない |
| 原因 | 自分に向いている仕事が分からない | 問題が起きている要素ではなく、今の気持ちを書いている |
| 課題 | 仕事で手応えを感じられていない | 問題を課題の欄に書いている |

## P02 Bさん: 前提・制約が多い

### 状況
小売チェーンの店舗で副店長として働いている。3歳の子どもがいる。
土日や夜のシフトが多く、子どもと過ごす時間が取れないことに悩んでいる。
配偶者も仕事の時間を変えにくく、家族の都合で住む場所も変えられない。

### 最初に書きそうな悩み(自由記述)
> 子どもとの時間が取れない。土日休みの仕事に転職したほうがいいのか考えている。

### 適切な記入例
| ステップ | 記入例 |
|---|---|
| 理想 | 平日の夕方と週末に、子どもと過ごす時間を確保しながら働いている |
| 前提・制約 | 子どもが小学校を卒業するまでは今の市内に住む／世帯の収入は今の水準を保つ／配偶者の勤務時間は変えられない |
| 現状 | 土日のどちらかと週3日の遅番があり、子どもと夕食をとれるのは週2日程度である |
| 問題 | 子どもと過ごせる時間が、理想とする平日の夕方と週末の時間に対して足りていない |
| 原因 | 店舗の営業時間に合わせたシフト勤務で、土日と夜の勤務が避けられない |
| 課題 | 土日と夜の勤務が少ない働き方に切り替える |
| 手段 | 本部(日勤・土日休み)への異動を希望し、並行して、同じ条件の市内の求人を調べる |

### 起きやすい取り違え
| ステップ | 入力しそうな文 | 起きていること |
|---|---|---|
| 現状 | 子どもが小さい | 変えられない条件(前提・制約)を現状に書いている |
| 原因 | 子どもがいるから | 変えられない条件を原因に書いている |
| 課題 | 土日休みの会社に転職する | 方向性ではなく、具体的な手段を書いている |
| 手段 | 市外の会社で在宅勤務の仕事を探す | 前提・制約(市内に住む)とは両立するが、収入の条件と両立するか確認が必要 |

## P03 Cさん: 手段が理想に入り込みやすい

### 状況
専門学校を卒業後、ホテルのフロントで3年働いている。趣味で作ったチラシを友人にほめられたことがあり、
Webデザイナー等制作の仕事への転職を考え始めた。今の仕事は接客が中心で、制作の仕事はない。
生活費のため、すぐに仕事を辞めることはできない。

### 最初に書きそうな悩み(自由記述)
> Webデザイナーに転職したい。何から始めればいいか分からない。

### 適切な記入例
| ステップ | 記入例 |
|---|---|
| 理想 | 自分が作ったデザインが、人に情報を届ける役に立っている |
| 前提・制約 | 生活費のため、準備の間は今の仕事を続ける／準備に使える時間は平日1時間程度 |
| 現状 | 仕事で制作に関わる機会はなく、デザインは趣味でチラシを数枚作った程度である |
| 問題 | 自分のデザインが人の役に立つ場面が、趣味の範囲にとどまっている |
| 原因 | 人からデザインを依頼される機会がなく、依頼に応えられるか試したことがない |
| 課題 | 人から依頼を受けてデザインを作る経験を積む |
| 手段 | ホテルの館内掲示やイベントのチラシを作る役割を、上司に申し出る |

### 起きやすい取り違え
| ステップ | 入力しそうな文 | 起きていること |
|---|---|---|
| 理想 | Webデザイナーになる | 職種(手段)を理想に書いている |
| 問題 | デザインのスキルが足りない | 理想との差ではなく、差を生む要素(原因)を書いている |
| 課題 | デザインスクールに通う | 方向性ではなく、具体的な手段を書いている |
| 手段 | 仕事を辞めて学習に専念する | 前提・制約(今の仕事を続ける)と両立しない |

## 作成上の注意

- 人物は架空とし、実在の人物や作成者自身の状況をそのまま使わない。
- 心身の不調など深刻な内容は、ここには含めない。深刻な内容への対応は、テストデータで別に確かめる。
- 記入例を変更した場合は、思考フレームワークとテストデータの該当箇所も合わせて直す。
