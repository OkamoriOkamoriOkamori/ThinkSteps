# AI判定の評価

## 1. 評価の方法
- データ: data/testcases.csv(調整用 tune / 検証用 test)
- 各版を3回実行し、正答率と判定の揺れを見る
- 指標の定義: testcases_spec.md の7章
- 注意: 2章の結果はすべて調整用データでの数値で、実力より高く出る

## 2. 改善の記録
### 第1版(judge_v1)
 実行日 / モデル / 件数: 2026-11-12 / gpt-6-astra / 調整用データ(tune)、採点対象55件(guardrail を除く)を3回
- テストデータ: data/testcases.csv(コミット e795d83 の時点)
- 結果:
  - 正答率: 46/55(84%)、46/55(84%)、45/55(82%)
  - 3回とも同じラベルを返したケース: 91%
  - ok のケースへの過剰指摘: 0件

- 分かった弱点(T037、T046 は正解ラベルの側の問題のため除く):
  1. 曖昧さの見逃し: 評価の言葉だけの理想(T002、3回とも ok)、程度が分からない現状(T016、3回とも外れ)、中身のない手段(T042、1回外れ)。気持ちだけの原因(T029)は3回とも検出できた
  2. 前提・制約の内容が現状・原因の欄に書かれたとき、wrong_category ではなく misaligned と判定(T015、T033、3回とも)
  3. 理想を打ち消しただけの現状を ok と判定(T013、3回とも)
  4. 手段の欄で、課題とのつながりを確かめない(T043「資格を取る」、3回とも ok)
  5. 問題を言い換えた原因を ambiguous と判定(T028、3回のうち2回)
  6. 判定の揺れ: 3回とも同じラベルだったのは58件中53件(91%)。揺れたのは T016、T026、T028、T042、T048
  7. 深刻な内容(T050、T051)でも、good_point に書き方をほめる文が入る(3回とも)
  8. 応答時間: 平均 4.9〜7.0秒。1回目のみ10秒超が9件(最長24.7秒)で、回による差が大きい
- できていたこと: 問題と課題の混同、手段の入り込みは3回とも全件正解。ok への過剰指摘0件。深刻な内容は2件とも検知し、日常的な疲れ(T052)は誤検知なし
