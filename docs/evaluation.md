# AI判定の評価

## 1. 評価の方法
- データ: data/testcases.csv(調整用 tune / 検証用 test)
- 各版を3回実行し、正答率と判定の揺れを見る
- 指標の定義: testcases_spec.md の7章
- 注意: 2章の結果はすべて調整用データでの数値で、実力より高く出る
- 最終検証(検証用データ)は、指示文とモデルを決めたあとに1度だけ行う
  - 全件を3回(src/run_ai_eval.py を検証用データで実行)
  - 深刻な内容のケース(T079〜T081)を10回(src/run_safety_eval.py test 10)
  - 実行後は、指示文を変えない

### 第3版(judge_v3)

#### 第2版で T002 が直らなかった原因の考察
- 第2版の「曖昧さの基準」には、理想についての項目がなかった(手段・原因・現状の項目のみ)
- さらに、ステップごとの具体性で「理想は方向性が読み取れればよい」としていたため、「やりがいのある仕事がしたい」は、方向性が読み取れる入力として ok と判定されていた

#### 設計の判断
- 「やりがい」のような本人の感じ方や評価だけの理想は、それが何を指すかによって、現状を見る観点も効果的な手段も変わる。現状は「理想と同じ観点から見た、現在の状態」であるため、理想の観点が定まらないと現状を書けない。そのため、ok ではなく ambiguous とし、それが何を指すのかを問う設計にした(thinking_framework.md 6.11)
- 見分ける基準は、言葉の種類ではなく「何がそろえばその状態になるのか(条件)が書かれているか」とした。気持ちだけの原因を ambiguous とするルール(6.8)と同じ考え方である
  - 例: 「自分の工夫が成果につながったと実感できる仕事をしている」は、「実感」という感じ方の言葉を含むが、条件(工夫が成果につながる)が書かれているため ok

#### 変更点(指示文)
- 判定ラベルに関わる変更
  - 曖昧さの基準に、本人の感じ方や評価だけで、条件が書かれていない理想の項目を追加
  - ステップごとの具体性で、理想を「方向性が読み取れればよい」から「何がそろえばその状態と言えるのかが読み取れる」に変更
  - ステップごとの具体性に、前提・制約と問題の行を追加し、全ステップをそろえた。問題は、理想と現状が書けていれば短い文や「〜の不足」でもよいと明記(過剰指摘を防ぐため)
  - 「抽象的なだけでは誤りとしない」ルールに、曖昧さの基準に当てはまる場合は ambiguous とする例外を明記
  - 重複していた手段の曖昧さの項目を1つにまとめた
- 問いに関わる変更(ラベルの正誤には影響しない)
  - 「はい・いいえ」で答えられる問いや、答えを含む問いを禁止するルールに、次の2つの例外を追加(thinking_framework.md 6.12)
    1. 前提・制約と両立するかを確かめる問い(前提・制約と両立しない手段に行き着いても意味がないため)
    2. wrong_category のときに、入力した欄のステップと looks_like のステップのどちらとして書いたかを確かめる問い(示すのはステップの区別であり、入力の答えではないため)
- その他
  - 入力の区切り(<input> と </input>)の記載を確認・修正 （v2で抜けていたため）

#### 変更点(判定基準の文書: thinking_framework.md)
- 指示文の変更に合わせて、2.3(具体性)、4.1(理想)、5.1(ラベル一覧)、6.9 を修正し、6.11・6.12 を追加
- 指示文にはあったが文書になかった基準を追加: 程度や状況が読み取れない現状は ambiguous(4.3。テストデータ T016 の根拠)
- 文書にあったが指示文になく、ラベルも決まっていなかった「悩みと関係がない前提・制約も問い返す」を削除(4.2、6.6)
- 深刻な内容のときは、問いだけでなく良い点(good_point)も返さないことを明記(2.5、5.3。第1版の弱点7に対応)

#### 変更点(テストデータ)
- 検証用データに T095「成長できる仕事に就いている」(P03 / ideal / ambiguous)を追加。指示文に使っていない言葉で、6.11 のルールが働くかを確かめるため。検証用データはまだ一度も実行していない段階で追加した

#### 確かめること
- T002 が ambiguous になるか
- 理想の判定を厳しくしたことで、ok の理想(T001、T005)を指摘していないか(過剰指摘率)
- 問題の具体性を書き足したことで、短い問題文(T085 など)を指摘していないか
- 前提・制約との両立や、ステップの区別を問う場面で、閉じた問いが例外の範囲を超えて増えていないか
